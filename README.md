# Paradise Nursery Shopping Application

A responsive React and Redux Toolkit e-commerce application for an online houseplant shop.

## Features
- Landing page with background image and Get Started button
- About Us company information
- 18 houseplants in three categories
- Product thumbnails, prices and Add to Cart controls
- Redux shopping cart with dynamic item count
- Quantity controls, delete buttons and automatic totals
- Checkout Coming Soon message and Continue Shopping navigation

## Technologies
React, Vite, JavaScript, CSS, Redux Toolkit and React Redux.

## Run locally
1. Run `npm install`
2. Run `npm run dev`
3. Open the local URL shown in your terminal.
